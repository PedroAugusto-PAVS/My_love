Experiência web romântica e interativa criada como homenagem de Dia dos Namorados. A página combina narrativa, música, contador de tempo, linha do tempo e galeria de fotos em uma interface responsiva.

## Sobre

O conteúdo começa com uma apresentação em tela cheia e revela a experiência principal após a interação do visitante. A proposta é transformar lembranças pessoais em uma página web simples, elegante e afetiva.

## Recursos

- Capa de abertura com chamada interativa.
- Contador dinâmico do tempo do relacionamento.
- Linha do tempo com momentos importantes.
- Galeria de fotos em estilo polaroid.
- Visualização ampliada das imagens.
- Música de fundo com controle de reprodução.
- Animações decorativas e layout responsivo.
- Tipografia personalizada via Google Fonts.

## Tecnologias

- HTML5 semântico.
- CSS3 para layout, responsividade e animações.
- JavaScript para interações, contador, música e galeria.
- Arquivos estáticos, sem dependências ou etapa de build.

## Como executar

### Abrir diretamente

Baixe o projeto e abra `index.html` em um navegador moderno.

### Usar um servidor local

```bash
git clone https://github.com/PedroAugusto-PAVS/My_love.git
cd My_love
npx serve .
```

Depois, acesse o endereço informado no terminal.

## Personalização

- Edite textos e datas em `index.html`.
- Substitua as imagens na pasta `img/`, mantendo os nomes usados no HTML ou atualizando seus caminhos.
- Troque a música em `music/musica.mp3`.
- Ajuste cores, tipografia e animações em `css/style.css`.
- Atualize as interações em `js/`.

> O projeto contém conteúdo pessoal. Antes de publicar uma versão derivada, confirme que todas as pessoas retratadas autorizam a exposição de fotos e informações.
